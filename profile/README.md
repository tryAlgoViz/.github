# TryAlgoViz

**Learn algorithms by watching them run.**

TryAlgoViz is an interactive learning platform where 40+ classic
algorithms are visualized step-by-step with a live debugger, paired
with structured roadmap, MDX explainers, and a multi-language code
playground.

→ **Live:** [tryalgoviz.com](https://tryalgoviz.com)
→ **Free during early access**

## What's inside

- 40+ algorithm visualizers — sort, search, graph, tree, DP, greedy,
  backtracking, more
- Step-by-step debugger with frame-by-frame state inspection
- 17-phase structured roadmap from foundations to advanced
- In-browser code playground (Python, C++, Java, Go, C)
- Practice problems with hints and test cases

## Built with

Next.js 16, React 19, TypeScript, MongoDB, NextAuth, Tailwind CSS,
PostHog. Deployed on Netlify.
